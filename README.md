# Binance AI Trader (Android)

An Android starter app for exploring Binance BTC/USDT market data and testing a simple simulated portfolio. Built with Kotlin and Jetpack Compose.

## Current features

- Reads the public BTC/USDT 24-hour ticker from Binance's public REST API.
- Displays the latest price and 24-hour percentage change.
- Simulates $100 buy/sell actions against a local paper portfolio.
- Makes no authenticated Binance requests and cannot place live trades.

## Build

1. Open this repository in Android Studio (a Gradle wrapper can be generated by Android Studio if needed).
2. Use JDK 17 and Android SDK 35.
3. Sync Gradle and run the `app` configuration on an Android 8.0+ device or emulator with internet access.

## Safety and scope

This is a demo, not financial advice or a production trading system. Crypto trading can result in substantial losses. The paper portfolio is in-memory and resets when the app process restarts. Do not put Binance API secrets in the Android app. Any future live-trading feature should be implemented behind a secure backend, use least-privilege keys with withdrawals disabled, and include explicit user consent, strict risk limits, audit logs, and a kill switch. Paper trading should remain the default.
